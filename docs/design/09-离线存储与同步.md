## 一、立项原则 vs 当前实现

| 原则 | 立项要求 | 当前实现 |
|------|---------|---------|
| 客户端权威 | SQLite 为真相源 | Server 侧 SQLite（分库），非客户端 |
| 无网可用 | 完整写作 + 检测 | 需本地起 Server；PWA-1 仅离线读项目列表 |
| 每项目一文件 | `*.worldforge.db` | ✅ `Data/Projects/{id}.worldforge.db` |
| 云副本 | PostgreSQL 可选 | 无 |

**结论**：架构 **方向** 对齐立项，**部署形态** 仍为开发期单体 API，尚未达到 PWA 离线写作。

## 二、当前存储路径

```
WorldForge.Server/Data/
├── _registry.worldforge.db            ← 注册库（Projects 表，EnsureCreated）
└── Projects/{projectId}.worldforge.db ← 项目库（Notes/Contradictions 等，Migrations）
```

每项目一 SQLite 文件已实现（v2）；数据仍驻留 Server 进程侧。

## 六、PWA 与 Workbox 策略（设计）

> 立项细节见 [reference/06 §五](./reference/06-前端与编辑器.md)。`vite-plugin-pwa` **已安装并启用**（PWA-1，见 `vite.config.ts`）；本节其余为设计规格。

### 6.1 分阶段目标

| 阶段 | 离线能力 | 依赖 |
|------|---------|------|
| **PWA-0**（月 3） | 可安装 + App Shell 离线 | Workbox precache JS/CSS/HTML |
| **PWA-1**（月 4） | 上次打开项目只读缓存 | runtime cache `GET /api/projects` |
| **PWA-2**（月 6+） | 真正离线写作 | 客户端 SQLite 或 Service Worker + IndexedDB 队列 |

MVP 验收最低线：**PWA-0**（reference/09 月 3 第 12 周）。

### 6.2 依赖与配置

```bash
npm install -D vite-plugin-pwa
```

`vite.config.ts`（设计）：

```typescript
import { VitePWA } from 'vite-plugin-pwa'

VitePWA({
  registerType: 'autoUpdate',
  manifest: {
    name: 'WorldForge',
    short_name: 'WorldForge',
    display: 'standalone',
    start_url: '/',
    theme_color: '#1e1b4b',
    background_color: '#0f1117',
    icons: [{ src: '/pwa-192.png', sizes: '192x192', type: 'image/png' }]
  },
  workbox: {
    globPatterns: ['**/*.{js,css,html,ico,png,svg,woff2}'],
    runtimeCaching: [/* 见 §6.3 */]
  }
})
```

### 6.3 Workbox runtimeCaching 规则

| 请求 | Handler | 说明 |
|------|---------|------|
| `https://fonts.*` | `CacheFirst` | 字体长期缓存 |
| `/api/health` | `NetworkFirst` | 探测在线；timeout 3s |
| `/api/projects` | `NetworkFirst` | 在线优先；离线回退缓存（PWA-1） |
| `/api/projects/*/manuscripts` | `NetworkOnly` | **PWA-0/1 不写缓存** — 避免 stale 正文 |
| `/api/**` POST/PUT/PATCH | `NetworkOnly` | 写操作不得 SW 拦截伪造成功 |

**原则**（reference/06 §5.2）：项目数据真相在 SQLite，**不经 SW 持久化**；SW 只缓存 shell 与可选只读 API 快照。

### 6.4 离线 UX

| 状态 | UI 行为 |
|------|---------|
| 在线 | 正常 |
| 离线 + 有 shell | 可打开已安装 App，顶栏「离线模式」 |
| 离线 + 无缓存 API | 项目列表空态 + 说明需联网首次加载 |
| 离线 + 编辑 | PWA-2 前 **禁用** 保存按钮或队列提示「待同步」 |

`navigator.onLine` + 可选 `GET /api/health` 双检。

### 6.5 与当前开发模式关系

| 模式 | 行为 |
|------|------|
| `npm run dev` | Vite HMR，**不**注册 SW（避免缓存干扰） |
| `npm run build` + 静态托管 | SW 生效 |
| 生产 | ClientApp `dist/` 由 Server `wwwroot` 或 CDN 提供 |

开发期仍用 Vite 代理 `/api` → 5280；PWA 生产构建需同源或配置 `workbox.navigateFallback`。

### 6.6 Electron 备选（reference/06 §5.3）

**评估点**：月 4–6，File System Access 无法稳定读 `.scriv` 目录时启动。

| 能力 | PWA | Electron |
|------|:---:|:--------:|
| 安装 | ✅ | ✅ |
| 离线 shell | ✅ | ✅ |
| 原生 SQLite | ❌ | ✅ |
| Scrivener 目录导入 | 受限 | ✅ |

Electron 与 PWA **共享 ClientApp 构建产物**；壳层替换，不重写 Vue。
