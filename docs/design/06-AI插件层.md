## 三、WorldBuildingPlugin

当前实现（摘要，全文见 `Plugins/WorldBuildingPlugin.cs`）：

1. 从 `ContradictionDetectionRequest` 组装实体卡片、时间线、章节摘录 prompt（§九）  
2. 经注入的 `IChatClient` 调 Ollama，模型取 `request.PreferredModel`（默认 `phi4-mini`）  
3. `ParseFindings` 解析 JSON → `ContradictionFinding[]`  
4. 空输入短路返回空；异常/超时 catch 后返回空（降级仅规则轨）

---

## 四、DI 注册

```csharp
var baseUrl = ollamaBaseUrl ?? new Uri("http://localhost:11434");
services.AddSingleton<IChatClient>(_ => new OllamaChatClient(baseUrl));
services.AddSingleton<WorldBuildingPlugin>();
services.AddSingleton<IContradictionDetectionPlugin>(sp => sp.GetRequiredService<WorldBuildingPlugin>());
services.AddSingleton<IWorldForgePlugin>(sp => sp.GetRequiredService<WorldBuildingPlugin>());
```

未装 Ollama 不影响启动：HTTP 失败由插件 catch 降级为空结果。

## 九、Ollama Prompt 与 JSON Schema（设计）

### 9.1 输入组装（WorldBuildingPlugin）

从 `ContradictionDetectionRequest` 构建 prompt 上下文：

| 块 | 来源 |
|----|------|
| 世界观摘要 | ProjectSettings.DefaultEra + 可选用户规则文本 |
| 实体卡片 | Notes 中 WorldCharacter 等 → JSON 摘要 |
| 时间线 | TimelineEvent 列表 |
| 相关段落 | FocusDocument 全文 + EntityLink 关联章 + Top-K 向量（Phase 1b） |

Token 预算：单批 ≤ 8k；超出则按章分批（reference/05 §五）。

### 9.2 System Prompt（草案）

```
你是世界观连续性编辑，只报告矛盾，不生成故事正文。
根据实体卡片、时间线与章节摘录，找出设定冲突。
输出必须是 JSON，符合 schema，不要 markdown 包裹。
```

### 9.3 输出 JSON Schema

```json
{
  "type": "object",
  "required": ["contradictions"],
  "properties": {
    "contradictions": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["type", "severity", "summary"],
        "properties": {
          "type": { "enum": ["AgeMismatch", "NameVariant", "LocationConflict", "TimelineOrder", "AttributeConflict"] },
          "severity": { "enum": ["Info", "Warning", "Error"] },
          "summary": { "type": "string" },
          "sourceDocumentId": { "type": "string", "format": "uuid" },
          "sourceExcerpt": { "type": "string" },
          "targetDocumentId": { "type": "string", "format": "uuid" },
          "targetExcerpt": { "type": "string" },
          "relatedEntityId": { "type": "string", "format": "uuid" },
          "suggestion": { "type": "string" }
        }
      }
    }
  }
}
```

映射至 `ContradictionFinding` → `ContradictionService.MapFinding`。

### 9.4 调用参数

| 参数 | 值 |
|------|-----|
| Model | `ProjectSettings.PreferredOllamaModel`（默认 phi4-mini） |
| Base URL | `http://localhost:11434` |
| Timeout | 2000ms；超时返回空并记日志 |
| Response format | Ollama `format: schema` 或 JSON mode |

### 9.5 降级

| 条件 | 行为 |
|------|------|
| Ollama 不可用 | 跳过插件轨，仅规则轨 |
| 超时 | 同上 + 可选「已加入队列」Phase 1b |
| 解析失败 | 丢弃当次 LLM 结果，不写入 |
