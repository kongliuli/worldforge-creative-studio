## 五、GitHub Actions 工作流（✅ 已落地）

**文件路径**：`.github/workflows/ci.yml` — 实际含三个 job：`dotnet`（build + test + EF migration smoke）、`frontend`（npm build）、`e2e`（Playwright chromium）。以下为设计草案，与实际文件的差异：EF smoke 与 e2e **均已启用**，非注释状态；解决方案文件为 `WorldForge.slnx`。

### 5.1 触发条件

| 事件 | Job |
|------|-----|
| `push` → `main` | build-test |
| `pull_request` → `main` | build-test |
| `push` tag `v*` | build-test + publish（Phase 1b） |

### 5.2 工作流草案

```yaml
name: CI

on:
  push:
    branches: [main]
    tags: ['v*']
  pull_request:
    branches: [main]

jobs:
  dotnet:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-dotnet@v4
        with:
          global-json-file: global.json

      - name: Restore
        run: dotnet restore WorldForge.sln

      - name: Build
        run: dotnet build WorldForge.sln -c Release --no-restore

      - name: Test
        run: dotnet test WorldForge.sln -c Release --no-build --verbosity normal

      # 04 §8 — Migrations 落地后启用
      # - name: EF migrate dry-run
      #   run: dotnet ef database update --project src/WorldForge.Infrastructure --startup-project src/WorldForge.Server -- --dry-run

  frontend:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: src/WorldForge.Server/ClientApp
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: npm
          cache-dependency-path: src/WorldForge.Server/ClientApp/package-lock.json

      - run: npm ci
      - run: npm run build

  # Phase 1b — PR 必填
  # e2e:
  #   needs: [dotnet, frontend]
  #   runs-on: ubuntu-latest
  #   steps:
  #     - uses: actions/checkout@v4
  #     - run: npx playwright install --with-deps
  #     - run: dotnet run --project src/WorldForge.Server &
  #     - run: npm run test:e2e --prefix src/WorldForge.Server/ClientApp
```

### 5.3 分支保护建议

| 规则 | 说明 |
|------|------|
| Required checks | `dotnet`、`frontend`、`e2e` |
| PR 必过 | `dotnet test` 全绿 |
| 禁止 force push main | reference/12 组织风险 |

### 5.4 与 Migrations 联动（04 §八）

`dotnet ef database update` 加入 CI 前需：

1. `IDesignTimeDbContextFactory` 就绪  
2. CI 使用 `:memory:` 或 temp 文件 SQLite 跑迁移 smoke  
3. 失败则阻断 merge  

### 5.5 发布 Job（tag `v*`，Phase 1b 设计）

```yaml
  publish:
    if: startsWith(github.ref, 'refs/tags/v')
    needs: [dotnet, frontend]
    runs-on: ubuntu-latest
    steps:
      - run: dotnet publish src/WorldForge.Server -c Release -r linux-x64 -o ./publish
      - run: npm ci && npm run build
        working-directory: src/WorldForge.Server/ClientApp
      - run: cp -r src/WorldForge.Server/ClientApp/dist publish/wwwroot
      # docker build / gh release upload — 见 §六
```

## 六、Docker 镜像（设计）

```dockerfile
# Dockerfile — 多阶段（设计，未提交）
FROM mcr.microsoft.com/dotnet/sdk:10.0 AS build
WORKDIR /src
COPY . .
RUN dotnet publish src/WorldForge.Server -c Release -o /app/publish

FROM mcr.microsoft.com/dotnet/aspnet:10.0 AS runtime
WORKDIR /app
COPY --from=build /app/publish .
ENV ASPNETCORE_URLS=http://+:8080
EXPOSE 8080
VOLUME ["/app/Data"]
ENTRYPOINT ["dotnet", "WorldForge.Server.dll"]
```

| 项 | 说明 |
|----|------|
| 数据卷 | `/app/Data` 挂载 SQLite |
| 静态资源 | `wwwroot` 含 ClientApp `dist`（05 §5.5） |
| 健康检查 | `GET /api/health` |
