## 一、后端在架构中的角色

WorldForge 是 **客户端权威** 产品。ASP.NET Core 10 后端 **不是** MVP 实时读写路径的必需组件。

```
MVP 核心路径（无网可用）：
  Vue PWA → 本地 SQLite → Ollama

可选云路径：
  Vue PWA → ASP.NET API → PostgreSQL
            ↑ 账户 / 备份 / 许可证
```

**设计目标**：后端尽量薄；复杂逻辑在 `WorldForge.Core` + 客户端。

## 二、MVP 后端最小集

### 2.1 API 清单

| 端点 | 方法 | 功能 | MVP |
|------|------|------|:---:|
| `/api/auth/register` | POST | 邮箱注册 | 可选 |
| `/api/auth/login` | POST | JWT 登录 | 可选 |
| `/api/auth/passkey/*` | * | WebAuthn | Phase 2 |
| `/api/license/verify` | POST | Gumroad 许可证 | ✅ |
| `/api/backup` | PUT | 上传加密项目 blob | — |
| `/api/backup` | GET | 下载最新备份 | — |
| `/api/user/profile` | GET/PATCH | 用户资料 | — |
| `/api/sync/*` | * | SyncQueue 合并 | Phase 2 |
| `/api/hub` | WS | SignalR Yjs | Phase 2 |

**MVP 可完全离线销售**：Gumroad 发 license key → 客户端本地校验（RSA 签名）→ 无需账户系统首发。

### 2.2 认证

| 机制 | 说明 |
|------|------|
| JWT 访问令牌 | 15 分钟过期 |
| 刷新令牌 | 30 天，旋转刷新 |
| Passkey | .NET 10 Identity WebAuthn，Phase 2 |
| 离线许可证 | JWT claims 含 `features: ["creative-pro"]` |

```csharp
// 功能门控示例
[Authorize]
[RequiresFeature("creative-pro")]
public IActionResult UploadBackup(...) { ... }
```

### 2.3 PostgreSQL 用途

| 表 | 用途 | MVP |
|----|------|:---:|
| `Users` | 账户 | 可选 |
| `Licenses` | Gumroad 关联 | ✅ |
| `ProjectBackups` | 加密 blob + 版本 | — |
| `SyncQueueRemote` | 多设备合并 | Phase 2 |

**不做 MVP**：完整多租户 SaaS、笔记内容云端 CRUD。

### 3.1 .NET Aspire（可选）

团队熟悉时可使用 Aspire 编排 PostgreSQL + API：

```csharp
var postgres = builder.AddPostgres("postgres");
var api = builder.AddProject<Projects.WorldForge_Server>("api")
    .WithReference(postgres);
```

开发/生产同一拓扑描述；MVP 单机 Docker 亦可。

## 四、Gumroad 许可证集成

MVP 付费流程（A 方案：先 Gumroad，内置付费延后）：

```
用户 Gumroad 购买
    → 收到 License Key
    → 客户端 POST /api/license/verify（或离线公钥验签）
    → 解锁：矛盾检测 / 导出 / 无水印
```

| 档位 | 价格 | 解锁 |
|------|------|------|
| 早鸟 | $69 | 全功能 |
| 正式 | $89–99 | 全功能 |
| AI 云模块 | $19/年 | Phase 2 云增强 |

Webhook：`POST /api/webhooks/gumroad` 记录销售、防密钥滥用（设备数限制 Phase 2）。

## 五、云备份（Phase 2）

```
客户端：
  1. 读取 .worldforge.db
  2. 用户主密钥加密（见 08-安全）
  3. 上传 ciphertext blob

服务端：
  PostgreSQL BYTEA 或 S3 兼容存储
  仅存 ciphertext，无法解密
```

**恢复**：下载 blob → 本地解密 → 打开项目。

## 七、明确不做

| 项 | 原因 |
|----|------|
| 云端 TipTap 实时编辑 MVP | 与离线战略冲突 |
| 服务端跑 Ollama | 隐私 + 成本；AI 在客户端 |
| 完整 billing 引擎 MVP | Gumroad 够用 |
| 小红书 / 飞书集成 | 赛道零复用 |

## 八、部署拓扑
