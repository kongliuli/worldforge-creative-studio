## 三、TipTap 扩展

### 3.1 EntityMention 节点

```typescript
// 概念结构 — @暗影领主 在正文中
{
  type: 'entityMention',
  attrs: {
    entityId: 'uuid',
    entityType: 'WorldCharacter',
    label: '暗影领主'
  }
}
```

**行为**：
- 输入 `@` 弹出 EntityAutocomplete（前缀 + 语义）
- 悬停显示实体卡片（年龄、派系、摘要）
- 点击跳转实体详情或 Split 分屏
- 保存时解析为 `EntityLink` 写入 SQLite

### 3.2 编辑器工具栏（MVP 精简）

| 功能 | MVP |
|------|:---:|
| 标题 H1–H3 | ✅ |
| 粗体 / 斜体 | ✅ |
| 链接 | ✅ |
| `@` 实体 | ✅ |
| 注释 / 高亮 | ✅ |
| 表格 / 公式 | — |
| 协作光标 | — |

### 3.3 分屏模式（SplitEditor）

```
┌─────────────────────┬─────────────────────┐
│  章节正文            │  选中实体卡片         │
│  TipTapEditor       │  或 第二章节对照      │
└─────────────────────┴─────────────────────┘
```

矛盾检测面板点击冲突项 → 自动打开 Split 对照 excerpts。

## 四、核心视图

### 4.1 ManuscriptTree

- 无限层级（卷 → 部 → 章）
- 拖拽排序 → 更新 `SortOrder`
- 右键：新建 / 删除 / 导出本章
- 字数统计 per 节点

### 4.2 EntityGraph（MVP 简版）

**MVP**：列表 + 关系表 + 可选 force-graph 简图  
**Phase 2**：完整力导向、筛选派系子图

### 4.3 TimelineView

- 横向时间轴或列表
- 事件拖拽改日期
- 点击事件 → 关联实体 + 相关章节

### 4.4 ContradictionPanel

- 过滤器：Severity / Status / 实体
- 批量「全部标记已读」
- 检测进度（全书扫描）

### 4.5 SemanticSearch

- 全局搜索框：关键词 + 语义模式切换
- 结果高亮章节片段

## 五、PWA 与桌面

### 5.1 PWA manifest

```json
{
  "name": "WorldForge",
  "short_name": "WorldForge",
  "display": "standalone",
  "start_url": "/",
  "theme_color": "#1e1b4b",
  "background_color": "#0f0f14"
}
```

### 5.2 离线策略

| 资源 | 策略 |
|------|------|
| JS/CSS/HTML | precache |
| 字体 | cacheFirst |
| API | networkFirst（MVP 几乎无必需 API） |
| 项目数据 | 仅 SQLite 本地，不经 SW |

### 5.3 Electron 备选（月 4–6 评估）

**触发条件**：File System Access API 不足以流畅 Scrivener 导入

| 能力 | Electron 增值 |
|------|--------------|
| 直接打开 `.scriv` 目录 | ✅ |
| 原生菜单 / 全局快捷键 | ✅ |
| 本地 SQLite native | ✅ 性能更佳 |
| 自动更新 | electron-updater |

## 七、Creative UI 皮肤

CSS 变量（与合成文档 §2.7 对齐）：

```css
:root[data-skin="creative"] {
  --font-size-base: 16px;
  --color-primary: #6366f1;
  --color-bg: #0f0f14;
  --color-surface: #1a1a24;
  --border-radius: 4px;
  --touch-target-min: 44px;
}
```

- 默认深色沉浸，可选浅色
- 写作区最大宽度 ~ 720px，两侧留白
- 减少非写作 UI 动画
