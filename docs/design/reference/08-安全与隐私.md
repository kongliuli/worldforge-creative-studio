## 一、安全等级定位

Creative 场景属于 **Security Level 0（Standard）**：

| 等级 | 场景 | WorldForge 阶段 |
|:----:|------|----------------|
| Level 0 | 创意 / 现场 | **MVP 当前** |
| Level 1 | 老年照护 | — |
| Level 2 | 健康 HIPAA | — |
| Level 3 | 遗产 后量子 E2EE | Phase 3（B 方案） |

**敏感数据类型**：未发表作品 IP、角色设定、私人创作笔记。  
**合规**：无 HIPAA / 法律科技；版权法保护未发表内容。

## 二、MVP 安全模型

### 2.1 默认：数据不出设备

| 数据 | 存储 | 上传 |
|------|------|------|
| 手稿正文 | SQLite 本地 | ❌ 默认不上传 |
| 实体 / 时间线 | SQLite 本地 | ❌ |
| 矛盾检测记录 | SQLite 本地 | ❌ |
| Ollama 推理 | 本机 localhost | ❌ |
| 许可证密钥 | 本地 secure storage | 仅验证时可选 |

**营销叙事**：「你的世界观和未发表章节默认只存在你的电脑上。」

### 2.2 传输安全

| 路径 | 措施 |
|------|------|
| API 调用 | TLS 1.3 |
| Gumroad Webhook | HTTPS + 签名验证 |
| 云备份 Phase 2 | TLS + 客户端加密 blob |

### 2.3 认证与授权

| 项 | MVP 方案 |
|----|---------|
| 认证 | JWT + 可选 Passkey Phase 2 |
| 授权 | 功能门控 claims（`creative-pro`） |
| 速率限制 | `PartitionedRateLimiter`：登录 5/min，API 60/min |
| 会话 | 刷新令牌旋转；异常设备可撤销 Phase 2 |

## 三、内容安全

| 威胁 | 缓解 |
|------|------|
| XSS（手稿 HTML） | TipTap sanitize；CSP nonce |
| CSRF | SameSite cookies + anti-forgery（若用 cookie） |
| 注入 | EF Core 参数化；无 raw SQL 拼接 |
| 恶意导入文件 | Scrivener/Markdown 解析 sandbox；大小限制 |

## 四、密钥模型预埋（Joplin 式）

MVP 可不启用 E2EE，但 **数据模型与密钥流** 需兼容 B 方案升级：

```
用户密码 / Passkey
    → KDF (Argon2id)
    → Master Key（永不上传）
        →  per-project Data Key
            → AES-256-GCM 加密 SQLite 导出 / 云备份
```

| 原则 | 说明 |
|------|------|
| 主密钥不出设备 | 服务端无法解密手稿 |
| 零知识云备份 | Phase 2 备份仅 ciphertext |
| 密码丢失 = 数据丢失 | 明确告知；无后门 |

---

## 五、Phase 3：后量子 E2EE（B 方案复用）

.NET 10 原生支持（合成文档 §1.2）：

```
ML-KEM (FIPS 203)  → 设备间会话密钥交换
ML-DSA (FIPS 204)  → 文档防篡改签名
AES-256-GCM        → 内容加密
```

| 对比 | Node/Electron | .NET 10 |
|------|--------------|---------|
| ML-KEM 原生 | ❌ 第三方未审计 | ✅ `System.Security.Cryptography` |
| 全平台统一 | ❌ | ✅ Win/Mac/Linux/iOS/Android |

**Creative 场景不营销「后量子」** — 用户无感知；遗产场景 LegacyVault 再作为信任卖点。

## 六、AI 隐私

| 项 | 策略 |
|----|------|
| 本地 Ollama | 推理数据不离开 localhost |
| 云 AI 模块 Phase 2 | 显式 opt-in；订阅层扣费；可仅发送必要 excerpts |
| 遥测 MVP | 无内容 telemetry；可选匿名 crash |
| 训练 opt-out | 不向任何模型提供商授权训练用户内容 |

---

## 七、许可证与防滥用

| 机制 | 说明 |
|------|------|
| 离线验签 | RSA/Ed25519 公钥嵌入客户端 |
| 在线验证 | 防密钥共享；设备数上限 Phase 2 |
| 盗版策略 | 技术防滥用适度；体验优先正版 |

---

## 八、用户可见隐私控制（MVP UI）

设置页必须包含：

- [ ] 数据存储位置说明（本地路径）
- [ ] Ollama 连接说明（仅 localhost）
- [ ] 云备份 opt-in 开关（Phase 2，默认关）
- [ ] 导出全部数据（Markdown + JSON）
- [ ] 删除账户 / 删除云备份

## 九、事件响应

| 事件 | 动作 |
|------|------|
| API 数据泄露 | 云侧仅 ciphertext/元数据；公告 + 强制改密 |
| 依赖 CVE | Dependabot + 72h 内补丁 |
| Gumroad 密钥泄露 | 轮换签名密钥 + 旧 key 黑名单 |
