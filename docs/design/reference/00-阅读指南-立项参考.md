## 一、本文档集用途

本目录（`docs/design/`）是 **WorldForge 创意工作者工作室** 的立项级技术设计说明，从调研报告提炼可执行的系统设计，供 2–3 人团队在 3–4 个月内落地 MVP。

**不是**：通用笔记产品架构、五场景并行 GTM、小红书赛道文档。  
**是**：A 方案（创意工作者）的完整技术图景 + 刻意边界 + 与后续 B/C/D/E 场景的 **引擎复用** 预埋。

**与代码的关系**：设计文档描述目标架构；[14-代码库映射与实现状态](./14-代码库映射与实现状态.md) 记录当前骨架已实现项与缺口。

## 五、术语表

| 术语 | 含义 |
|------|------|
| **客户端权威** | SQLite 为数据源真相；PostgreSQL 仅为可选副本 |
| **引擎内核** | `Note` TPH、Project、Contradiction、租户无关编排 — 全垂直场景复用 |
| **租户模板** | `ITenantTemplate`：实体类型、插件 ID、规则 ID、皮肤、安全等级、功能开关 |
| **Creative 租户** | 月 0–12 唯一启用的 GTM 模板（WorldForge） |
| **矛盾检测** | 跨章节 / 时间线 / 实体属性连续性校验，非内容生成 |
| **规则 vs 插件** | 规则 = 确定性 `IContradictionRule`；插件 = LLM `IContradictionDetectionPlugin` |
| **Phase 2** | MVP 后 6–12 月增强项（Yjs、云 AI、EPUB 等） |
| **Level 0 安全** | Creative 标准加密；Legacy E2EE 为 Level 3（Phase 3） |
