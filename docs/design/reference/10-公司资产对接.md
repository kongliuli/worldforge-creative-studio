# 10 — 公司资产对接

> **关联源文档**：`0705调研报告/03-公司资产复用补充.md`、`0705调研报告/AI笔记垂直场景/A-创意工作者工作室.md`

---

## 一、总体原则

WorldForge 走 **路径 B**（03 公司资产 §七）：

```
月 0–4   Ollama 本地 + CandyAI 模板；NewAPI 仅服务可选云增强
月 4+    Agent 就绪 →「角色对话检验」$19/年，走订阅层 + NewAPI
```

| 原则 | 说明 |
|------|------|
| 离线优先不变 | 核心矛盾检测不依赖公司云端 |
| NewAPI / 订阅 = 可选增值 | 非 MVP 阻塞项 |
| 不做 CandyAI 竞品 | 结构化世界构建 + 检测，非陪伴聊天 |

---

## 二、四层公司架构中的位置

```
Layer 4 · WorldForge 产品
Layer 3 · @company/persona-templates     ← MVP 强协同
Layer 2 · 订阅计量（方案 7）              ← Phase 2 云 AI
Layer 1 · NewAPI 中转站                  ← Phase 2 云 AI
```

**两套 Quota 不可合并**（03 §3.1）：
- **订阅 Quota**：用户套餐「还能用多少」— 云 AI 模块扣此
- **渠道 Quota**：NewAPI 上游 Key — 运维成本

WorldForge MVP **不经过 Layer 1/2**。

## 四、CandyAI 类角色模板（MVP 重点）

### 4.1 能力映射

| CandyAI 能力 | WorldForge 映射 | 需 Agent |
|-------------|----------------|:--------:|
| 角色卡 JSON 模板 | Entity 预填 + CustomFieldsJson | ❌ |
| 关系 / 羁绊模板 | CharacterRelationship 边类型 | ❌ |
| 固定口吻 Prompt 片段 | 导出/展示用，非聊天 | ❌ |
| 对话式人格一致性检验 | 云 AI 模块 | ✅ Phase 2 |

### 4.2 共享包建议

```
@company/persona-templates/
├── schema/
│   └── character-card.v1.json    # JSON Schema
├── templates/
│   ├── fantasy-hero.json
│   ├── fantasy-villain.json
│   └── ttrpg-npc.json
└── prompts/
    └── voice-snippets/           # 非聊天，用于导出样例
```

**导入流程**：

```
用户选择模板
    → 解析 JSON → WorldCharacter + CustomFieldsJson
    → 可选：预生成 Relationships 边
    → 写入 SQLite
```

**预估工作量**：抽 schema **1 周**（03 §十）

### 4.3 产品边界红线

| 做 | 不做 |
|----|------|
| 模板降 onboarding 摩擦 | 陪伴式 daily chat |
| 结构化字段预填 | 情感依赖型 UX |
| 导出角色卡 JSON | 与 CandyAI 抢 DAU |

KPI 仍是 **export + 矛盾检测周活**，不是聊天 DAU。

## 五、NewAPI 中转站（Phase 2）

### 5.1 启用场景

| 场景 | 说明 |
|------|------|
| 云 AI 矛盾检测 | 更大上下文模型 |
| 角色对话检验 | Agent 多步调用 |
| Embedding 云端 | 低算力设备降级 |

### 5.2 请求规范

```http
POST /v1/chat/completions
X-Product: creative-cloud
X-Member-Id: {subscription_user_id}
```

NewAPI 只做渠道路由；套餐扣减在 **订阅层** 完成。

### 5.3 MVP 落地

**零依赖**。开发时预留 `IChatClient` 工厂：

```csharp
IChatClient CreateClient(AiMode mode) => mode switch
{
    AiMode.Local => ollamaClient,
    AiMode.Cloud => cloudClient,  // Phase 2
    _ => ollamaClient
};
```

## 六、订阅计量层（Phase 2）

定位：公司级 **订阅计量中台**（非 Langfuse 竞品）

| 能力 | WorldForge 用法 |
|------|----------------|
| member_id ↔ 套餐 | 云 AI $19/yr 档位 |
| 按 product_id 扣减 | `creative-cloud` |
| 超额策略 | 降级本地模型 / 停服 |

**与主力公司套餐**：可打包「含 N 万 token/月」；WorldForge 云模块可单独 SKU。

**MVP**：无需实现；Gumroad 断买断即可。

---

## 七、Agent 平台（Phase 2，不阻塞 MVP）

| 阶段 | 能力 | WorldForge 消费者 |
|------|------|------------------|
| 现在 | 无 Agent | Ollama + 硬编码 Plugin |
| Agent MVP | 单 Agent + 工具 | 替换「角色对话检验」Prompt 链 |
| Agent v2 | 多步 + 记忆 | 深度人格一致性 |

**对外叙事**：MVP 不承诺 Agent；roadmap 写「角色对话检验（Beta）」。

**扣费**：Agent 多步 LLM 在订阅层 **任务级汇总扣减**（避免用户看到「一次对话扣 10 次」）。

---

## 八、与小红书赛道的关系

| 维度 | 关系 |
|------|------|
| 产品代码 | **零复用** |
| NewAPI / 订阅 | 若公司并行飞书 bet，共享 Layer 1/2 |
| 团队 | **同一团队只选一个产品主 bet** |

WorldForge 团队不应同时主力飞书闭环 GTM。

## 九、8 周验证计划（含公司资产）

| 周 | 动作 |
|:--:|------|
| 1 | Ollama 全员可用；persona-templates schema 定稿 |
| 3–4 | 导入 3 套角色模板 demo；矛盾检测端到端 |
| 7–8 | 若启用云 AI pilot：单用户 upstream 成本 < ¥200/月；订阅扣减与 NewAPI 日志可对账 |
