# 09 — MVP 范围与路线图

> **关联源文档**：`0705调研报告/AI笔记垂直场景/A-创意工作者工作室.md`、`0705调研报告/01-总体项目选型筛选报告.md`、`ai笔记调研项目图景/可行方案筛选报告.md`

---

## 一、MVP 定义（3–4 个月）

**一句话**：Web PWA + 桌面可安装，Markdown/SQLite 本地存储，实体世界构建 + 基础时间线 + Ollama 矛盾检测，Scrivener/Markdown 导入，Gumroad $69 早鸟。

---

## 二、必须有 vs 延后

### 2.1 MVP 必须有

| 类别 | 功能 |
|------|------|
| **平台** | Web PWA + 桌面（Electron 或纯 PWA 安装） |
| **存储** | Markdown 兼容 + SQLite 本地权威 |
| **世界构建** | 实体类型：角色 / 地点 / 事件；双向 `@` 链接 |
| **写作** | TipTap 章节编辑器 + 手稿树 |
| **时间线** | 基础时间线视图 + 实体关联 |
| **AI** | Ollama 矛盾检测 MVP + 名称补全 |
| **搜索** | 全文 + 基础语义搜索 |
| **导入** | Scrivener / Markdown |
| **导出** | Markdown |
| **付费** | Gumroad 外部（或简易 license 验证） |

### 2.2 明确延后

| 功能 | 目标阶段 | 原因 |
|------|---------|------|
| 多人协作 | Phase 2 | Yjs 复杂度 |
| 云同步 / CRDT 多设备 | Phase 2 | MVP 单设备足够 |
| 插件系统 | Phase 3 | scope |
| 移动端原生 MAUI | 月 12+ | 工具链 |
| 内置完整付费 | PMF 后 | Gumroad 先验证 |
| DM 跑团屏 | Phase 3 | 非核心 PMF |
| EPUB/PDF 正式导出 | Phase 2 | QuestPDF |
| 互动地图 | Phase 3 | World Anvil 级深度后置 |

## 五、6 月成功指标

来自 A 方案 §5.2：

| 指标 | 目标 |
|------|------|
| 付费用户 | ≥ 200 |
| NPS | ≥ 40 |
| 矛盾检测周活 | ≥ 60% 付费用户 |
| 社区提及 | Reddit / PH 前 10 自然讨论 |

**Go/No-Go**：
- **Go**：矛盾检测周活 ≥ 40% 且 NPS ≥ 30 → 加大 GTM
- **Pivot**：导入 / 写作体验好评但 AI 不用 → 强化规则引擎或降 AI 宣传
- **No-Go**：6 月付费 < 50 且 NPS < 20 → 复盘再定
